# Laravel Mini CMS

## Overview

Simple CMS built with Laravel featuring page management, services management and contact form handling.

## Live Demo

https://live-demo-application-production.up.railway.app

## Features

### Version 1.0

- Services CRUD
- Contact form
- Contact message management
- Admin dashboard

### Version 1.1

- Railway deployment
- MySQL database integration
- Dynamic page routing
- Pages CRUD

### Version 1.2

- Dynamic mini page builder
- AJAX section loading
- Text section
- Two-column section (1/2 + 1/2)
- Dynamic page rendering
- Slug-based routing
- Section editing
- Section deletion
- Services submenu navigation

## Planned Features

### Version 1.2.1

- Database transactions
- Basic feature tests

### Version 1.3

- Dynamic menu management
- Menu visibility controls
- Section ordering
- Additional content sections
- Page publishing status

- Laravel
